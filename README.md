# Десятка — готовый сайт для GitHub Pages

Загрузка Excel → выбор победителей → MP4 для Reels.
Без регистрации, собственного сервера, API-ключей и расширения.

## Залить на GitHub и передать на тест

1. Создайте публичный репозиторий на GitHub, например `desyatka`.
2. Распакуйте ZIP. Загрузите **содержимое** папки в корень репозитория: index.html, файлы .js/.css и папки fonts, kit, vendor, examples. Не загружайте один ZIP вместо файлов и не помещайте всё во вложенную папку.
3. Откройте Settings → Pages. Source: Deploy from a branch. Branch: main. Folder: / (root). Нажмите Save.
4. Дождитесь завершения публикации. Скопируйте ссылку сайта в Settings → Pages и отправьте тестировщику.

В этой поставке уже есть .nojekyll; файл index.html должен оказаться в корне репозитория.

## Провести розыгрыш

1. Откройте опубликованную ссылку в браузере. Для первого теста используйте examples/comments-example.xlsx — там 30 вымышленных участников.
2. Загрузите Excel в студии. Проверьте лист и столбцы автора/текста. При необходимости нажмите «Применить столбцы».
3. Укажите число победителей и режим шансов: один шанс каждому автору либо каждому комментарию. Один автор выигрывает только один раз.
4. Запустите всех победителей или выбирайте по одному. Нажмите «Победители в Excel»: отдельный список содержит имя, ник, кликабельный профиль и комментарий, а также поля «Статус связи» и «Заметки». Протокол доступен отдельно в JSON.
5. Нажмите «Сделать Reels» → «Создать MP4» → «Скачать MP4». Формат: 1080×1920 / H.264 / 30 fps. Есть вариант 720p. Ролик без звука, музыку можно добавить в Instagram.

## Подготовить Excel

Один комментарий на строку. Рекомендуемые заголовки: username, comment, необязательно full_name, comment_id и is_reply. Ник автора, его имя и текст комментария — разные столбцы. Проверьте предпросмотр «Автор / Комментарий» перед применением. Текст вместо ника не будет принят. Можно выбрать столбцы вручную; нумерацию строк сайт сохраняет для сверки.

В результатах и MP4 имя автора, ник и его комментарий показываются отдельно. Имя берётся из full_name / «Имя автора», если такой столбец есть; ник нужен обязательно, чтобы открыть профиль. Длинный комментарий может сокращаться в ролике, полный текст сохраняется в Excel.

Количество комментариев видно только в панели подготовки и протоколе. В кадре розыгрыша и в MP4 его нет. Анимация: орбитальные кольца, прокрутка имён с замедлением, раскрытие победителя и конфетти. Она не меняет случайный выбор.

## Как передать данные и результаты

Ссылка открывает одинаковый сайт, но не общую базу. Каждый загружает Excel в своём браузере. Файл и результаты сохраняются в этом браузере, если разрешено IndexedDB; на сервер не отправляются. Для передачи результатов скачайте Excel / JSON / MP4. Не очищайте данные браузера до скачивания.

Реальную базу комментариев не требуется добавлять в репозиторий. В examples лежат только вымышленные тестовые данные. Файлы в публичном репозитории доступны посетителям.

## Локально

Для локального теста в папке сайта запустите `python3 -m http.server 8080 --bind 127.0.0.1` и откройте http://localhost:8080 . Для Windows можно использовать `python` вместо `python3`.

Видео требует HTTPS (GitHub Pages) или localhost и современный браузер с Worker / OffscreenCanvas. Не запускайте запись видео через file:// двойным щелчком по index.html. На слабом телефоне выберите 720p или создайте видео на компьютере.

Локальный протокол фиксирует настройки и результаты, но не является независимым сертификатом честности. Подписки, лайки и другие условия конкурса проверяются отдельно. Демо явно помечено, пример таблицы содержит вымышленных участников.

Исходники сайта открыты в .js/.css; сборка и npm install для публикации не нужны. Сторонние компоненты описаны в THIRD-PARTY.md.
