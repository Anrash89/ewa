От таблицы до победителей

  1. В студии загрузите Excel с авторами и комментариями. Для проверки можно взять пример Excel с вымышленными участниками.
  2. Проверьте лист и столбцы «Автор / username» и «Текст комментария». Если нужно, нажмите «Применить столбцы».
  3. Выберите число победителей и правила: один шанс автору или каждому комментарию. Один автор выигрывает один раз.
  4. Запустите весь розыгрыш или выбирайте по одному. При необходимости исключите аккаунт организатора.
  5. Скачайте победителей в Excel и протокол JSON. Для ролика откройте «Видео», выберите оформление и нажмите «Создать MP4».

Как устроен тест по ссылке

Отправьте тестировщику ссылку GitHub Pages. Он открывает сайт и загружает свой Excel. Регистрация, сервер и расширение не нужны.

База и результаты сохраняются только в том браузере, где проводился розыгрыш. Другие люди по этой ссылке не увидят загруженный файл. Для передачи результатов скачайте Excel, JSON или MP4.

Формат таблицы

Первая строка — заголовки. Рекомендуемые столбцы: username, comment, необязательно comment_id и is_reply.

Один комментарий — одна строка. Не объединяйте всю базу в одну ячейку.

Видео

MP4 / 9:16 / 1080×1920. Число комментариев в ролик не попадает. Музыку можно добавить при публикации в Instagram.

Сохранение

Не очищайте данные браузера до скачивания результатов. Демо помечено как демонстрация.
